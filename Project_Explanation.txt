Project Name: Student Academic Performance Predictor
Created For: Complete Analytics and Code/Flow Explanation

=======================================================
1. PROJECT OVERVIEW (Ye Project kya hai?)
=======================================================
Ye project ek Data Science aur Machine Learning based web application hai. Iska main kaam hai students ke past data (jaise padhai ke ghante, attendance, neend, etc.) ko analyze karke unke "Final Marks" predict karna. Sath hi, ye dashboard ke through data ko graphs aur charts me samajhne (Data Analysis) me madad karta hai.

=======================================================
2. LIBRARIES USED (Kaunsi Libraries ka use hua hai?)
=======================================================
Code me main roop se in Python libraries ka use kiya gaya hai:

1. Streamlit (st): Ye sabse main library hai jisse website ka pura user interface (UI) banaya gaya hai. Isme bina HTML/CSS ke Python me hi buttons, forms, aur sidebars banaye ja sakte hain.
2. Pandas (pd): Data manipulation ke liye. Jo aapka `student_performance_dataset.csv` file hai, usko read karke table (DataFrame) me convert karne aur naye data ko save karne me Pandas ka use hua hai.
3. NumPy (np): Maths aur numbers ke liye. Prediction ke time agar model 102 marks predict kar de, toh `np.clip` ka use karke usko 0 se 100 ke beech limit kiya gaya hai.
4. Scikit-Learn: Machine Learning ka core. Isi library ke models (jaise Random Forest) ko train kiya gaya tha jo ab naye students ke marks predict karte hain.
5. Matplotlib (plt) & Seaborn (sns): Inka use 'Data Analysis' aur 'Model Metrics' wale pages par sundar graphs (Histograms, Heatmaps, Bar charts) banane ke liye kiya gaya hai.
6. Joblib: Machine Learning models ko train karne ke baad unko save (model_bundle.pkl) aur wapas code me load karne ke liye iska use hua hai taaki har baar code run hone par model ko naye sire se train na karna pade.

=======================================================
3. HOW THE PROJECT FLOWS (Website aur Code kese kaam karta hai?)
=======================================================
Jab app.py run hota hai, toh flow kuch is tarah chalta hai:

STEP 1: Data aur Models ka Load hona (Initialization)
Code run hote hi sabse pehle `pd.read_csv` se saara data load hota hai aur `joblib.load` se pre-trained Machine Learning models memory me aa jate hain. Code automatic calculate karta hai ki kis model ka score (R2 Score) sabse best hai aur usko `best_model` bana deta hai.

STEP 2: Sidebar Navigation
Streamlit ka `st.sidebar.radio` function ek menu banata hai jisme 5 pages hain. User jis page par click karta hai, if-else logic ke through wo specific page screen par dikhta hai.

STEP 3: Pages ka Logic

-> [Home]: Yahan basic Dashboard hai. Pandas ka use karke total records aur models ki ginti show hoti hai. Ek table (dataframe) me data ka thoda sa preview dikhaya jata hai.

-> [Prediction]: Ye project ka main engine hai. 
   - Yahan `st.form` ka use karke ek form banaya gaya hai jisme user sliders aur dropdowns se student ki details dalta hai.
   - Jab "Run Prediction" button press hota hai, code un sabhi inputs ko ek Pandas DataFrame me pack karta hai.
   - Fir `best_model.predict(new_student)` call hota hai jo input ko analyze karke final marks batata hai.
   - Us marks ke base par ek custom function `category(marks)` check karta hai ki student "At Risk" hai ya "Excellent".
   - NEW FEATURE: Agar "Save record to dataset" checkbox tick hai, toh code us data ke liye naya Student ID generate karta hai (jaise S501) aur usko CSV file me `.to_csv(mode='a')` karke append (save) kar deta hai.

-> [Data Analysis]: Yahan Matplotlib aur Seaborn ka use karke dataset ko graphs me plot kiya gaya hai. Jaise Study hours aur Final marks ke beech ka relation (Scatter plot), aur konsi cheez marks par kitna asar dalti hai uske liye Correlation Heatmap.

-> [Model Metrics]: Yahan project me use hue sabhi machine learning models (jaise Linear Regression, Random Forest) ko compare kiya gaya hai ki kisme kitni error (RMSE) hai aur kaun kitna accurate (R2 Score) hai. Best model ka 'Feature Importance' graph batata hai ki prediction me sabse bada role kiska tha (jaise shayad Attendance ya Previous Marks ka).

-> [About]: Ek simple text page jo project ki detail aur variables ke baare me bataata hai.
