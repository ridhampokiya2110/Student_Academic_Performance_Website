# 🎓 Student Academic Performance Prediction Website

## Run on your laptop

### 1. Open Command Prompt / Terminal in this folder

### 2. Install requirements
```bash
pip install -r requirements.txt
```

### 3. Start the website
```bash
streamlit run app.py
```

The website will open in your browser.

## Files
- `app.py` — Streamlit website
- `student_performance_dataset.csv` — project dataset
- `model_bundle.pkl` — trained ML models and evaluation results
- `best_student_performance_model.pkl` — selected trained model
- `requirements.txt` — required Python packages

## Website sections
- Home
- Student Prediction
- EDA & Insights
- Model Comparison
- About

## Important
The included dataset is synthetic/illustrative and is intended for an academic demonstration.
